# README

## Descripción
Se implementó un sistema de puntos para el bot de la cafetería en **n8n** usando **Google Sheets**.

## Funciones
- Calcula **1 punto por cada $5** de compra.
- Actualiza los puntos del usuario según su **telegram_id**.
- Agrega la opción **"Ver mis Puntos"** al menú.
- Muestra el total de puntos acumulados al usuario.

## Tecnologías
- n8n
- Google Sheets
- Telegram Bot
